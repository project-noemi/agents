# Operations Skills

Reusable drafting, planning, and compliance skills for volunteer-club officers, assistants, and MSP/hosting operations teams working within approved information and legal boundaries.

| Skill | Output | Used by |
| --- | --- | --- |
| [Meeting Minutes](../../../skills/operations/meeting-minutes.md) | Evidence-linked draft minutes, actions, and unresolved questions | Club Operations; secretary or knowledge assistant |
| [Annual Calendar](../../../skills/operations/annual-calendar.md) | Officer-year plan with ownership, dependencies, and date confidence | Club Operations; president or planning assistant |
| [Speaker Brief](../../../skills/operations/speaker-brief.md) | Session brief, timed running order, and venue confirmations | Club Operations; programme or event assistant |
| [Abuse Takedown](../../../skills/operations/abuse-takedown.md) | Compliant copyright/DMCA/abuse notice handling with jurisdiction-specific frameworks | MSP/Hosting Operations; abuse response or support agents |

A Rotary deployment example is in [docs/examples/rotary-club-operations.md](../../examples/rotary-club-operations.md). Load these skills through the [Club Operations persona](../../../agents/operations/club-operations.md) or another caller that enforces equal or stricter boundaries. They prepare drafts; human officers approve records and handle external actions.

The Abuse Takedown skill is designed for hosting and MSP providers handling copyright, DMCA (US 17 USC 512), EU DSA (Reg. 2022/2065), and other abuse notices. It enforces human approval gates for customer-impacting actions and integrates with ticketing (Autotask, Zendesk, etc.) and control panel systems (WHMCS, Blesta, etc.) via MCP protocols where available.
