# Operations Skills

Reusable drafting and planning skills for Rotary club officers and other assistants working within the club's approved information boundary.

| Skill | Output | Used by |
| --- | --- | --- |
| [Rotary Meeting Minutes](../../../skills/operations/rotary-meeting-minutes.md) | Evidence-linked draft minutes, actions, and unresolved questions | Rotary Club Operations; secretary or knowledge assistant |
| [Rotary Annual Calendar](../../../skills/operations/rotary-annual-calendar.md) | July–June plan with ownership, dependencies, and date confidence | Rotary Club Operations; president or planning assistant |
| [Rotary Speaker Brief](../../../skills/operations/rotary-speaker-brief.md) | Session brief, timed running order, and venue confirmations | Rotary Club Operations; programme or event assistant |

Start with the [Rotary operations guide](../../examples/rotary-club-operations.md) for the canonical NotebookLM links, direct-chat instructions, source-verification status, and synthetic exercises. Load these skills through the [operations persona](../../../agents/operations/rotary-club-operations.md) or another caller that enforces equal or stricter boundaries. They prepare drafts; human officers approve records and handle external actions.
