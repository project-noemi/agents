# Agent Gardeners & Anti-Pattern Control Guide

Agents amplify patterns in the codebase. Gardeners (human or agent) prevent anti-pattern creep and keep the paved path clear.

## Practices

- Detect recurring agent mistakes and turn them into lint rules or structural constraints.
- Run periodic cleanup routines.
- Align with Guardian agents and QA/Risk Manager personas.
- Ensure each improvement makes the next agent work better, not worse.
