# Software Factory / Michelin Kitchen Automations Guide

Scale from individual agent use to a specialized, long-lived agent factory that produces high-quality PRs at volume while maintaining trust.

## Key Elements

- Specialized agents (line cooks, sous chefs, reviewers).
- Routines and automations for recurring work.
- Trust-gated reduction of human review as verification improves.
- Integration with coding-loop, Grok Bot swarm/routines, MCP, and noemi-agent machine identity.

## Building the Factory

1. Establish a strong verification inner loop first.
2. Define specialized long-lived agents with clear roles.
3. Automate event-driven workflows (issue → plan → PR).
4. Monitor quality metrics (revert rate, etc.).
