## Classification procedure

Apply these steps independently to each email:

1. Identify the sender, subject, and actual purpose of the message.
2. Check the positive and negative category definitions below.
3. Check every content-based category independently, including possible secondary labels.
4. Apply the explicit category exceptions.
5. Review the proposed labels. Remove any category supported only by an incidental mention, weak association, or unsupported assumption.
6. Return the complete set of supported categories. An empty set is valid when no category qualifies.

Do not classify solely by keywords. Do not require a single primary category, and do not exclude a valid secondary category merely because it is less prominent.
